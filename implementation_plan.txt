### Build sequence

We'll do it in **small verified stages**:

**Stage 1 — Project foundation**

```text
CareFlow/
├── backend/
│   ├── app/
│   ├── database/
│   ├── models/
│   ├── schemas/
│   ├── agents/
│   ├── orchestration/
│   └── main.py
│
├── frontend/
│   └── React + TypeScript + Tailwind
│
├── .env
├── .gitignore
└── README.md
```

We'll first make sure:

```text
React → FastAPI → SQLite
```

works.

**Stage 2 — Synthetic hospital data**

We'll create:

* 1 hospital
* 3 departments
* 5 doctors
* 20 beds
* synthetic patients
* appointments/admissions where needed

**Stage 3 — Monitoring Agent**

We'll make:

```text
patient vitals
      ↓
Monitoring Agent
      ↓
NORMAL / WARNING / CRITICAL
```

and test it independently.

**Stage 4 — Triage Agent + Gemini**

We'll implement Gemini structured output:

```text
patient information
       ↓
Gemini
       ↓
priority
confidence
reasoning
```

with Pydantic validation and a fallback if Gemini fails.

**Stage 5 — Resource Agent**

Actual deterministic Python logic:

```text
ICU availability
doctor availability
ward availability
       ↓
resource recommendation
```

No LLM doing the allocation math.

**Stage 6 — LangGraph Orchestrator**

Then we'll connect:

```text
Monitoring
     ↓
Triage
     ↓
Resource
     ↓
Risk Engine
     ↓
Approval / Auto-execute
```

**Stage 7 — Approval + Audit**

We'll implement:

```text
agent_decision
approval
audit_log
```

and the approve/reject API.

**Stage 8 — React dashboard**

Only after the backend workflow works, we'll build the UI around it.

**Stage 9 — WebSocket**

Then:

```text
Backend event
     ↓
WebSocket
     ↓
Dashboard updates live
```

**Stage 10 — What-if simulations**

We'll add:

* 🚨 Emergency Surge
* 🏥 ICU Full
* 👨‍⚕️ Doctor Unavailable

**Stage 11 — Agent handoff visualization**

Finally:

```text
Monitoring
    │
    ▼
Triage
    │
    ▼
Resource
    │
    ▼
Approval
    │
    ▼
Bed Reserved
```

with timestamps and status.
